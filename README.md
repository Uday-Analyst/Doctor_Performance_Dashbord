Doctor Performance Dashboard
A Tableau dashboard project for monitoring doctor performance, patient distribution, revenue trends, specialization insights, and payment behavior.
📌 Project Overview
This dashboard provides an interactive healthcare analytics view designed to help track doctor performance and operational metrics.
Dashboard Features

•	Patients handled by each doctor

•	Revenue contribution by doctor

•	Top-performing specializations

•	Monthly revenue trends

•	Revenue distribution by payment mode

•	Interactive filters (Gender, Month, Specialization)

KPIs & Insights

•	Compare doctor workload

•	Track revenue generation patterns

•	Identify top medical specializations

•	Monitor payment preferences

Tools Used

•	Data Visualization

•	Healthcare Analytics

How to Use

•	Open the Tableau dashboard

•	Apply filters to explore trends

•	Review charts and compare performance
